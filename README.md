# Cardiac Pathology Prediction - IMA205 Challenge 2025

This repository contains a solution developed for the IMA205 Challenge 2025, which focuses on the classification of cardiac pathologies using Cardiac Magnetic Resonance Imaging (CMRI) data.

## Objective

The goal of this project is to automatically classify patients into one of five diagnostic categories based on features extracted from CMRI data:

- NOR: Healthy controls  
- MINF: Myocardial infarction  
- DCM: Dilated cardiomyopathy  
- HCM: Hypertrophic cardiomyopathy  
- ARV: Abnormal right ventricle

Accurate classification is crucial for early diagnosis and improved treatment outcomes in clinical cardiology.
